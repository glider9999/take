# TakeChat 双端功能对齐矩阵 (Feature Parity Matrix)

> **发布基线**：Phase 2 封版交付 (HEAD `1a7f8f2`，已并入工单 13 抛光补丁单与工单 14 微修单)  
> **形态定义**：
> - **Web 轻装版**：静态托管纯前端（GitHub Pages 口径），零服务端中心中转；
> - **Desktop 完全版**：Tauri 2.0 桌面客户端（macOS / Windows / Linux 原生）；
> - **Docker 本地版**：本地容器编排 Web 实例（docker-compose 本地独立启动）。

## 二、双端一致性红线与安全约束

1. **绝对禁止伪装可用与本机裂图**：
   - 浏览器版对于无法直连本地 IPC（子进程、伪终端）或本机私网（ComfyUI）的动作，必须在视觉上明示「桌面版可用」导向徽章，并在触发时弹出说明；绝不允许假装正在执行、假装出图或静默失败；
   - 演示与种子数据一律使用安全占位，严禁写入任何 localhost 或 127.0.0.1 真实地址。
2. **零 Node.js 私有依赖与零 direct Tauri 依赖**：
   - 核心包全部保持纯前端 TypeScript，桌面专用能力统一通过抽象依赖注入，保证双壳平滑运行。
3. **安全硬化贯穿全平台**：
   - 报错信息与外部返回字符串统一采用 DOM `textContent` 渲染，严禁 `innerHTML` 拼接远端错误文本；
   - 白名单拦截强制先置：ACP capabilities 别名与 PTY allowedAliases 名单外命令在构造即抛错。
