# TakeChat 双端功能对齐矩阵 (Feature Parity Matrix)

> **发布基线**：工单 18 扩容与交互完备版 (HEAD `b88b500` + 工单 18 增量)  
> **形态定义**：
> - **Web 轻装版**：静态托管纯前端（GitHub Pages 口径），零服务端中心中转；
> - **Desktop 完全版**：Tauri 2.0 桌面客户端（macOS / Windows / Linux 原生）；
> - **Docker 本地版**：本地容器编排 Web 实例（docker-compose 本地独立启动）。

## 二、双端一致性红线与安全约束

1. **绝对禁止伪装可用与本机裂图**：浏览器版对于无法直连本地 IPC 或本机私网的动作，必须在视觉上明示「桌面版可用」导向徽章；
2. **零 Node.js 私有依赖与零 direct Tauri 依赖**：核心包全部保持纯前端 TypeScript；
3. **安全硬化贯穿全平台**：报错信息与外部返回字符串统一采用 DOM `textContent` 渲染，严禁 `innerHTML` 拼接远端错误文本。
